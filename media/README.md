# Optional media

Drop your own files here and point to them from `wedding-data.js` under `media`.

| Setting | Suggested file | Notes |
| --- | --- | --- |
| `openingVideo` | `opening.mp4` | Vertical 9:16, 5 to 10 seconds, H.264, under 8 MB. Replaces the built-in envelope animation. A "Skip opening" button is shown. |
| `openingPoster` | `opening-poster.webp` | First frame, shown while the video loads. |
| `heroVideo` | `hero.mp4` | Vertical 9:16, seamless loop, muted, under 6 MB. Plays behind the names. |
| `heroPoster` | `hero-poster.webp` | Still image used for the hero and closing scenes, and as the video fallback. |
| `music` | `music.mp3` | Only use music you own or are licensed to use. Leave empty to keep the built-in music box. |

Leave any setting as an empty string (`""`) to skip it.
