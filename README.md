# Wedding invitation: Magnolia

An illustrated, scroll-driven wedding invitation: a sealed envelope that parts to reveal a lakeside-arch hero, then an invitation note, a live countdown, a schedule timeline, venue with map and calendar buttons, dress code, an RSVP card and a closing scene. Static site, no build step, no dependencies.

## Run it

```bash
python3 -m http.server 8000     # then open http://localhost:8000
```

Any static host works (Netlify, Vercel, GitHub Pages, Cloudflare Pages, S3). Upload the whole folder.

## Make it yours

Everything personal lives in **`wedding-data.js`**: names, date and time, schedule, venue, dress code, RSVP email and optional media. Nothing else needs editing.

- **RSVP**: set `rsvp.email`. Guests fill the form and their email app opens with a pre-written reply. Nothing is stored on the site.
- **Date**: `wedding.dateISO` drives the countdown and the "Add to calendar" file. Include the UTC offset, e.g. `+05:30`.
- **Music**: with `media.music` empty, a soft built-in music-box melody plays after the envelope is opened. To use your own track, put the file in `media/` and set the path. Only use music you have the rights to.
- **Video**: optional vertical (9:16) clips for `openingVideo` (replaces the envelope animation) and `heroVideo` (loops behind the names). See `media/README.md`.

## Background animation

- **Opening (about 5 s):** the wax seal warms and bursts into a starburst, golden light races along the embossed vines and ignites the petal outlines with sparkles, the top flap tilts open, a warm bloom fills the screen, and the envelope sinks away to reveal the hero. "Skip opening" is shown throughout.
- **Hero (8 s loop):** calm, then a breeze. The tied-back sheer curtains lift and sweep inward, rose petals swirl through the arch, ripples spread across the lake, the sun glows and the flowers sway, then it settles and repeats.
- Pausing motion (or reduced-motion) returns the hero to its still, resting pose. Animation stops while the hero is off-screen.
- Scenes are layered SVGs (`assets/hero-*.svg`) generated by `node tools/build-art.js`; the timings live in `css/invitation.css` (hero loop) and `js/opening.js` (opening).

## Colours

Set in `:root` at the top of `css/invitation.css`: `--paper`, `--ink`, `--accent`, `--metal`. The artwork's palette lives in `tools/build-art.js`.

## Accessibility and motion

The invitation stays inert until the envelope is opened, focus moves to the couple's names, and every animation is disabled for visitors who prefer reduced motion. A "Pause motion" button is always available.
